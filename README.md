# 🎓 Eduzone التعليميه (EduZone Platform)

> **المنصة التعليمية الرائدة لطلاب الثانوية العامة، الدبلومات الفنية، والكورسات الجامعية وبنك الأسئلة التفاعلي.**  
> **تطوير وتصميم: Eng.Abdullah**

---

## 🌟 نظرة عامة (Overview)

منصة **Eduzone التعليميه** هي بيئة تعليمية ذكية متكاملة مصممة خصيصاً لتلبية احتياجات الطلاب والمعلمين في مصر والعالم العربي. تجمع المنصة بين سهولة التصفح، التصميم العصري الفاخر (Dark Luxury)، المحتوى الأكاديمي المعتمد، والأدوات التفاعلية المبتكرة لمساعدة الطلاب على التفوق والوصول إلى أعلى الدرجات.

---

## 🚀 المميزات والوظائف الرئيسية (Core Features)

### 1. المسارات التعليمية الشاملة (Educational Tracks)
* **الثانوية العامة (علمي وأدبي ولغات):** كبسولات إنقاذ فيزيائية، خرائط الكيمياء العضوية، النحو والبلاغة، والجغرافيا السياسية.
* **التعليم الفني والتجاري:** مبادئ المحاسبة المالية، قيود اليومية، التوجيه المحاسبي، والرسم الفني الصناعي (نظام 3 و 5 سنوات ونظام الجدارات).
* **الكورسات الجامعية و ICDL:** دورات احتراف تطبيقات Microsoft Office، إكسيل التحليل المالي، ودوال البحث المتقدم.
* **معسكرات الفيديو التعليمية (1080p HD):** محاضرات مكثفة مع ملخص نواتج التعلم وأبرز النقاط الامتحانية.

### 2. بنك الأسئلة التفاعلي (Question Bank - 1600+ سؤال)
* بنك أسئلة ذكي يضم **200 سؤال** في كل مادة (تاريخ، فيزياء، كيمياء، لغة عربية، محاسبة مالية، رياضيات، فلسفة، علم نفس).
* **نظام البابل شيت الحديث:** إجابة فورية، كشف النتيجة مع التفسير العلمي المعتمد فور الحل.
* **نظام النقاط والـ VIP:** أول 60 سؤال مجاناً لكل الطلاب، و140 سؤال متقدم لباقة التفوق VIP.
* البحث السريع، القفز برقم السؤال، وحساب النتيجة الإجمالية.

### 3. نظام التحقق والـ OTP برقم الهاتف المصري (Auth & OTP)
* فحص صارم ومخصص لأرقام الهواتف المصرية (11 رقماً بالضبط تبدأ بـ 010 أو 011 أو 012 أو 015) باستخدام التعبير النمطي:
  ```regex
  ^01[0-2,5]{1}[0-9]{8}$
  ```
* كود تحقق OTP فوري (كود تجريبي `123456`) مع إمكانية التعبئة التلقائية ومؤقت إعادة الإرسال.
* حماية وسرية تامة لكود المشرفين والإدارة.

### 4. نظام الإشعارات الفوري والبث الحي (Push Notifications & Service Worker)
* دعم الـ **Service Worker** (`sw.js`) لظهور إشعارات النظام (Push Notifications) حتى خارج الموقع أو عند تصغير المتصفح.
* مزامنة حية وفورية عبر **BroadcastChannel** و **LocalStorage** للبث الفوري لجميع الطلاب بمجرد إرسال المشرف لأي إشعار.
* شارة جرس الإشعارات مع عداد التنبيهات غير المقروءة ونغمات تنبيه صوتية (Audio Chime).

### 5. محرك التحفيز ونقاط الخبرة (Gamification Engine)
* احتساب نقاط الخبرة (+50 XP لقراءة مذكرات، +80 XP لمحاضرات الفيديو، +25 XP لحل الأسئلة، +40 XP لجلسات التركيز).
* نظام مستويات متدرج (طالب مبتدئ ➔ مجتهد ➔ متفوق ➔ عبقري ➔ أسطورة).
* أوسمة تفوق رقمية (Badges) وسجل نشاطات تفاعلي.

### 6. أدوات المذاكرة العملية (Study Tools)
* **محاكي قيود اليومية المحاسبية:** تدريب عملي لاختيار الحساب المدين والدائن والتأكد من توازن القيد.
* **بنك القوانين والمعادلات:** مرجع سريع لأهم قوانين الفيزياء والمحاسبة.
* **مؤقت المذاكرة (بومودورو):** فترات تركيز (15، 25، 50 دقيقة) مع مكافآت نقاط إضافية.
* **تحميل المذكرات بصيغة المستندات:** حفظ المذكرات بضغطة زر دون الحاجة لبرامج خارجية.

### 7. نظام الترحيب الذكي (3-Step Onboarding)
* يظهر للزوار الجدد فقط لشرح المنصة وتسهيل بدء الاستخدام أو التصفح كزائر.

## 🛠 التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Frontend):** React 19, TypeScript, Vite
* **التصميم والتنسيق:** Tailwind CSS, Cairo Google Font, Lucide Icons
* **الخلفية والخدمات:** Service Worker API, BroadcastChannel API, Web Audio API, LocalStorage Sync
* **التوافق:** Responsive Mobile-First & Android App Ready

## 💻 طريقة التشغيل والتركيب المحلي (Local Setup)

### المتطلبات الأساسية
* Node.js (الإصدار 18 أو أحدث)
* npm أو yarn أو bun

### خطوات التثبيت والتشغيل:
1. فك ضغط ملف المشروع أو استنساخ المستودع.
2. تثبيت الحزم والمكتبات:
   ```bash
   npm install
   ```
3. تشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
4. فتح المتصفح على العنوان:
   ```text
   http://localhost:3000
   ```

### بناء نسخة الإنتاج (Production Build):
```bash
npm run build
```
سيتم إنشاء مجلد `dist/` جاهز للرفع على أي خادم استضافة (Apache, Nginx, Vercel, Netlify, Cloudflare Pages, cPanel).

## 📁 هيكلية ملفات المشروع (Project Structure)

```text
├── index.html                  # مدخل الـ HTML الرئيسي مع خط Cairo والوسوم التعريفية
```
